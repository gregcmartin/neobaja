# Gameplay behavior reference

The linked ZgzInfinity/OutRun repository is pinned at commit
`5d4f5409cc79021eacc757a164ff00515253fc51` and licensed GPL-3.0. BAJANEW does
not include that repository or any of its code.

`OUTRUN_BEHAVIOR_ORACLE.md` is the fuller clean-room observation contract.
`IMPLEMENTATION_ORACLE_NOTES.md` is a shorter record from the rejected build
and is preserved for comparison only.

Allowed carry-forward: high-level relationships among throttle, coast, brake,
steering, recentering, curves, road surface, rivals, collision, HUD feedback,
and race progression.

Forbidden carry-forward: source or line-by-line paraphrase, numeric constants,
data structures, maps, route data, assets, names, code architecture,
presentation, or trade dress.
