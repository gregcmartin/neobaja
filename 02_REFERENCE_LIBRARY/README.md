# Reference library

This folder contains the only images copied into BAJANEW. They have different
rights and roles; none should be treated casually as implementation art.

## Primary user mockups

`primary-user-mockups/` contains four user-supplied Neo Geo presentation
mockups. They are the primary visual target for composition, stage mood,
vehicle presence, depth, density, lighting, and HUD hierarchy.

Keep them byte-for-byte unchanged. They are inspection-only: do not ship,
trace, crop, repaint, transform into tiles, feed as an image-edit base, or copy
their visible brands and trade dress.

## Secondary BAJA: Edge of Control HD images

`secondary-baja-edge-of-control-hd/` contains eight copyrighted screenshots
from the official Steam listing. Use them privately and only to observe
off-road terrain, race-pack composition, dust, suspension, elevation, lighting,
and vehicle physicality. Do not redistribute them with a ROM or public release,
and do not copy their pixels, assets, liveries, layouts, or branding.

If a secondary image conflicts with a user mockup, the user mockup controls the
desired Neo Geo presentation.

## Gameplay behavior oracle

`gameplay-behavior-oracle/` records behavioral relationships observed from the
pinned GPL-3.0 ZgzInfinity/OutRun repository. It is not permission to copy code,
constants, maps, data, art, presentation, or trade dress. A restart must
implement those relationships independently and test them relationally.

## Developer splash

`developer-splash/devsplashlogo.jpg` is the exact user-provided Max Cruz Racing
splash and is the one image intended to appear in the game after a new,
reproducible native conversion. Its hash is pinned in the accompanying README.

## Hash record

`REFERENCE_MAP_ORIGINAL.md` preserves the old reference map and original
Desktop source paths. `99_MANIFESTS/FILES.sha256` is the current BAJANEW hash
inventory. Always verify the actual files rather than relying on prose.
