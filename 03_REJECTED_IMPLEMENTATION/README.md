# Rejected implementation quarantine

Everything in this folder documents the rejected BAJA Outrun implementation.
It is here to explain failure, not to seed the restart.

- `WHAT_FAILED.md` is the curated comparison between the requested game and
  the observed result.
- `screenshots/` contains selected native MAME frames from the rejected build.
  They are negative evidence and must never be used as visual references or
  shipping assets.
- `source-docs/` preserves the old implementation's own claims and state. Old
  PASS language, build instructions, scores, constants, and architecture are
  not current requirements.

No rejected source code, ROM, converted asset, generated raw, build tool, or
test harness was copied into BAJANEW.
